# Assignment 1 – Object Oriented Programming

**Department:** Artificial Intelligence  
**College:** College of Information Technology  
**University:** University of Fallujah  
**Academic Year:** 2026–2027

## Assignment Overview

This assignment contains four programming tasks using C++.

### Task 01 – Resize Array
Create a dynamic array and resize it to double its original size. Copy the original elements into the first half and their doubled values into the second half.

### Task 02 – Diagonal Matrix
Create a square matrix and check whether all elements outside the main diagonal are zero.

### Task 03 – Left Substring and Destructor
Extract a specified number of characters from the left side of a string using a function. Implement a Destructor function to deallocate dynamically allocated memory.

### Task 04 – Student Grades
Create a dynamic array to store student grades and calculate:
- Minimum grade.
- Maximum grade.
- Average grade.
- Median grade.

## Libraries Used
- `iostream`

## Important Concepts
- Functions

- Dynamic Memory Allocation

- Function Overloading
- Memory Deallocation

All tasks are implemented using C++ with attention to code organization, meaningful variable names, and proper memory management.
