C++ OOP Lab 2 Assignments
Solutions for Lab 03 (CIT-AI Department, University of Fallujah).
Summary
Task 01 (Inventory System): Struct-based inventory program that generates uppercase codes (COM_31203), calculates a 40% selling markup, and displays stock via const InventoryItem* pointers.
Task 02 (Carpet Estimator): Application using nested structs (FeetInches, RoomDimension) and a dynamic array to calculate room carpeting costs via a menu-driven interface. Memory is freed with delete[].
Build & Run
# Task 01
g++ task1.cpp -o task1 && ./task1
# Task 02
g++ task2.cpp -o task2 && ./task2
